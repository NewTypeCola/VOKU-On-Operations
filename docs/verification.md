# 구현 검증 — 2026-10-12

## 자동 검증

- TypeScript 검사 및 Vite 배포 빌드 통과 (`dist/`).
- PGlite PostgreSQL 통합 테스트 16개 통과. 단순 모의 호출 대신 기존 커뮤니티 마이그레이션과 새 운영 SQL을 실제 실행했습니다.
- 가입 분리, 회원/게시판 관리자 접근 차단, 이메일/세션/MFA, 직접 테이블 차단, 역할별 권한, 검색/페이지, 변경 이력, 동시 변경 충돌, 일괄 작업 롤백, 신고 처리, 회원 제한, 기존 게시판 보호, 사진 정책을 검증했습니다.
- 실제 Supabase의 운영자 임시 가입·조회 검증은 하나의 트랜잭션에서 실행 후 ROLLBACK했습니다. 인증 메일이나 지속되는 검증 계정을 생성하지 않았습니다. 최고운영자 역할, 7일 차트, 기존 게시글 32개·회원 2명 조회를 확인했습니다.
- 실제 공개 API에서 비로그인 운영 조회 401 차단, 기존 커뮤니티 목록 200 응답을 확인했습니다.
- 기존 커뮤니티 함수 32개의 정의 해시와 기존 관리자 역할을 적용 전후 대조했습니다.

## 브라우저 검증

1440×1000, 1280×900 데스크톱에서 예시 모드를 확인했습니다. 페이지 전체 가로 넘침이 없습니다. 목록은 공간이 부족할 때 표 영역 안에서 가로 스크롤합니다.

페이지 이동, 검색, 상세보기 뒤 검색 조건 유지, 일괄 숨김, 필수 사유, 신고 처리/이력, 기존 게시판 관리자 처리 버튼 부재, 운영자 등록, 빈 첨부파일 목록, 운영 안내를 실제 클릭으로 확인했습니다. 콘솔 오류/경고가 없습니다. 예시 모드는 실제 서버에 연결하지 않습니다.

- `artifacts/dashboard-desktop.jpg`, `artifacts/posts-desktop.jpg`: 데스크톱 화면
- `artifacts/browser-verification.json`: 브라우저 관측 결과
- `artifacts/database-verification.json`: 기존 함수·역할 보존
- `artifacts/live-api-verification.json`: 실제 공개 API 점검
- `artifacts/webapp-preservation.json`: 읽기 전용 웹앱 파일 해시 대조

## 완료에 사용자 입력이 필요한 부분

최초 운영자의 실제 비밀번호, 이메일 인증번호, 인증 앱 QR 등록은 사용자가 직접 입력해야 합니다. 이 단계의 실사용 완료를 주장하지 않습니다. 등록/권한 검사는 DB 통합 테스트와 실제 서버의 ROLLBACK 검증으로 확인했습니다. 외부 호스팅 배포는 수행하지 않았습니다.
